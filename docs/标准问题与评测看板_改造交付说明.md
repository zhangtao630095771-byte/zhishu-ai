| 筛选 | 仅「状态」「审核态」2 个下拉 | 关键词 / 关联指标 / 状态 / 验证状态 / 审核态 / 创建日期，共 6 项 |

- 状态：`active→启用中`、`archived→已归档`、`disabled→已停用`
- 验证状态：`verified→已验证`、`unverified→未验证`（「待验证」「验证失败」为预留筛选项，后端当前无此枚举值，已在审查报告 D1 说明）
- 审核态（既有能力）：`draft→草稿`、`pending→待审核`、`approved→已通过`、`rejected→已驳回`

## 六、核心指标计算口径文档

### 6.1 核心运行概况（业务运行数据，来源 `query_records` / `feedbacks`）

| 指标 | 分子 | 分母 | 统计范围 |
|---|---|---|---|
| 实际取数总次数 | — | — | `query_records` 全部记录 |
| 已验证业务案例 | `review_status='approved'` | — | `query_records` |
| 业务结果准确率 | 已验证业务案例 | 取数总次数 | 同上（**人工审核通过占比，≠SQL执行成功率**） |
| SQL 生成成功率 | 有非空 `sql` 的记录 | 取数总次数 | `query_records` |
| SQL 执行成功率 | `ok=1` 记录 | 有 SQL 的记录 | 同上（**执行成功 ≠ 业务正确**） |
| 用户反馈解决率 | `status='resolved'` | 反馈总数 | `feedbacks` |

### 6.2 知识资产质量（来源 `sql_experience`）

| 指标 | 口径 |
|---|---|
| 正式 Golden SQL | `trust_level='golden'` |
| 黄金候选（待发布） | `trust_level='golden_candidate'`（**≠ 正式 Golden**） |
| 普通 SQL 案例 | `trust_level='candidate'` |
| Golden SQL 复用率 | `SUM(reuse_count of golden/golden_candidate)` / `recall` 事件总数 |
| 待审核候选规则 | 经验规则 `candidate + draft` 数量 |
| 知识冲突 | 经验规则 `draft`（存在冲突待处理）数量 |

### 6.3 AI 评测质量（来源 `evaluation/reports/*.json`，离线评测集）

18 个指标，全部中文化。关键口径：

| 中文名 | 原指标 | 说明 |
|---|---|---|
| 综合准确率 | Overall Accuracy | 各维度整体正确率 |
| 意图识别准确率 | Intent Accuracy | 正确识别查询意图 |
| 指标识别准确率 | Metric Accuracy | 指标不遗漏/不多算 |
| 数据表召回率 | Table Retrieval Recall | 正确召回所需表 |
| SQL正确率 | SQL Accuracy | SQL 语义正确 |
| SQL执行成功率 | SQL Execution Success | SQL 能成功执行 |
| 时间识别准确率 | Time Accuracy | 时间范围/口径正确 |
| 知识依据准确率 | Grounding Accuracy | 引用有知识依据 |
| 幻觉率 | Hallucination Rate | 越低越好 |
| 拒答准确率 | Abstention Accuracy | 该拒答时正确拒答 |

> **重要区分**：本区块是**离线评测集**结果（样本量=评测集条数），与「核心运行概况」的**线上真实取数**是两个不同口径，页面已明确标注、不混算。

### 6.4 错误归因（12 类统一分类，评分维度 → 分类映射）

| 统一分类 | 评分维度来源 |
|---|---|
| 意图识别错误 | `intent`、`abstain` |
| 指标识别错误 | `metrics`、`forbidden` |
| 数据表选择错误 | `tables` |
| SQL语法错误 | `sql_contains`、`sql_not_contains` |
| SQL执行失败 | `ok` |
| 业务结果错误 | `result` |
| 时间范围错误 | `time` |
| 知识召回错误 | `grounding`、`hallucination` |
| 其他问题 | `format` |
| 字段选择错误 / JOIN关系错误 / 权限问题 | **当前评测逐题评分无直接数据来源，计数为 0（页面已注明，不虚构）** |

## 十、P1 / P2 待办与差异处理

本轮完成 **P0 全部**。P1/P2 及关键差异的处理建议已在《改造前功能审查报告》第四章列出，核心结论：

1. **标准问题库为空（0 条）**：看板相关指标如实展示 0/N/A，未填模拟数据。建议后续从「SQL 经验 → 黄金案例」沉淀第一批标准问题。
2. **标准问题（golden_cases）与 Golden SQL（sql_experience）当前是两套独立体系、无关联字段**：任务书 §3.5 的「标准问题→验证→Golden 候选→审核→正式 Golden」联动属 P1，需设计关联字段与迁移，本轮未强行加外键（避免擅自改库）。
3. **验证状态枚举**：后端仅 `verified/unverified` 两值，任务书要求的「待验证/验证失败」四值需 P1 迁移扩充，本轮前端按现有值映射 + 预留筛选项。
4. **评测实验/消融实验（P2）**：评测报告已含 `experiment_id` 字段，P2 可基于既有报告做前后对比（`baseline` 快照已在本轮接口中预留）。
