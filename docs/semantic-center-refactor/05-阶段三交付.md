### 1.2 指标三分类推导（务实，不依赖空的 depends_metrics）

- **复合指标 composite**：metric_type ∈ ratio/rate，或名称含「率/占比/比例」（比率需分子分母）
- **衍生指标 derived**：有 sql_template（计算模板）
- **原子指标 atomic**：其余

实测分布：**原子 47 + 复合 10**（衍生 0，因现有 sql_template 均空）。用户可在指标 Tab 手动调整分类。

### 1.3 维度派生

从 `column_comments` 扫描字段，`dimension_type`（人工覆盖）优先 + `detect_dimension`（自动识别时间/地域/状态/类型/渠道），派生 **143 个候选维度**，用户「采纳」后写入 `semantic_dimensions`（source=manual、status=approved）。
