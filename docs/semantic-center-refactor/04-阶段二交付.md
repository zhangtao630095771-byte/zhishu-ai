## 一、实施内容

### 1.1 后端（新增 `ontology.py` 领域模块 + 10 个路由）

**数据模型（严格复用，不复制本体）：**

| 落地 | 类型 | 说明 |
|---|---|---|
| `ontology_attributes` | 新增表 | 实体↔属性登记（属性本体仍在 column_comments / dict_entries） |
| `ontology_rules` | 新增表 | 实体↔规则登记（规则本体仍在 metric_constraint / prompts.sql_rules） |
| `entities.entity_code` | 加列 | 实体英文标识（历史行回填 NULL，诚实标记未填） |
| Object（业务实体） | 复用 `entities` | 不加列之外不动 |
| Relation（实体关系） | 复用 `relationships` | 完全复用 |
| Attribute 本体 | 复用 `column_comments`/`dict_entries` | 只读派生 |
| Rule 本体 | 复用 `metric_constraint`/`sql_rules` | 只读引用 |
| Action | **预留** | 暂不建表（避免空表，后续需要再加） |

**新增接口（10 个，均走 `_current_username` 权限）：**

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/ontology/entities` | 实体列表（含 entity_code） |
| GET | `/api/ontology/entity/{name}` | 实体详情（实体+字段属性派生+登记+关系+规则） |
| PUT | `/api/ontology/entity/{name}` | 编辑实体（英文标识/描述/粒度/主键） |
| GET | `/api/ontology/graph` | 关系画布数据（节点+边，含关联键/基数） |
| GET/POST | `/api/ontology/attributes` | 属性登记 读/写 |
| DELETE | `/api/ontology/attributes/{id}` | 删属性登记（不删本体） |
| GET/POST | `/api/ontology/rules` | 规则登记 读/写 |
| DELETE | `/api/ontology/rules/{id}` | 删规则登记（不删本体） |
