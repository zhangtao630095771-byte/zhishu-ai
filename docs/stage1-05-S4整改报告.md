# S4 整改报告：检索降噪与字段级召回

> 时间：2026-10-20
> 阶段：S4（任务 7）
> 目标：减少无关指标挤占候选表；让“只报字段名”的问题也能召回正确主表；用真实失败案例对比。

---

## 1. 结论

1. **指标按问题类型降噪**：问比例不再召回金额指标；问金额不再召回纯比率指标；问总数不再召回金额指标。
2. **指标按业务线收敛**：已识别实体时，金额/计数指标依赖表必须与实体主表有交集，跨业务线指标直接丢弃。
3. **字段级关键词召回**：把人工字段注释短语加入表的 keywords；用户只写“信息费默认比例”也能命中司机表。
4. **字段命中豁免实体过滤**：否则会被 P2 的错误实体当成“跨业务线表”删掉。
5. **配置分布不套时间窗**：问“有几种搭配”时不再默认加“近 30 天”，避免把全量配置算成当月新增。
6. **实体别名收紧**：「代驾司机激活费」移除泛化别名“资金流水”，修掉资金流水问题误召回激活费表。

## 3. 端到端验证

| 问题 | 结果 |
|---|---|
| 司机信息费三类比例搭配 | `ok=True`，23 种组合，SQL 无时间过滤，仅用司机表 |
| 2025年9月大板信息费总额 | `ok=True`，1 行 |
| 2025年9月代驾完单率 | `ok=True`，1 行，SQL 使用 `status=40` |

司机问题最终 SQL：

```sql
SELECT "信息费默认比例", "信息费提升比例", "信息费降低比例", COUNT(*) AS "司机数"
FROM (
  SELECT COALESCE(default_information_fee_ratio,0) AS "信息费默认比例",
         COALESCE(extra_information_fee,0)          AS "信息费提升比例",
         COALESCE(activation_reduce_ratio,0)        AS "信息费降低比例"
  FROM ctc_data_warehouse.ods_tu_driver_all
  WHERE is_delete = 0
) AS t
GROUP BY "信息费默认比例", "信息费提升比例", "信息费降低比例"
ORDER BY "司机数" DESC
```

> 「提升比例」仍是假设口径，SQL 注释与自然语言回答都会声明；业务确认前不当作权威结论。
