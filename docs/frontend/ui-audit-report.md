## 4. 核心页面问题诊断

### 4.1 AI 智能取数页（当前最重要、问题最集中）

| 目标要求 | 现状 | 判定 |
|---|---|---|
| 欢迎语 | 只有标题「请输入你的问题」 | **缺** |
| 常见业务问题示例 | 仅 1 条输入框 placeholder | **缺** |
| 执行过程可视化时间线 | 有「处理过程」卡片，但展示的是召回的表/指标/字典/检索方式/尝试次数等**结果性信息**，不是分步时间线 | **形态不符** |
| 结果表格 | 有，中文表头 + 原始编码 + 字典中文释义 | 有 |
| 适合的图表 | 无图表库、无容器 | **缺** |
| SQL 默认折叠 | SQL 卡片直接展示排版 SQL | **需改** |
| 查看 SQL / 执行信息 | 有 SQL 卡片 + 校验报告 + 信任条 | 有 |
| 右侧数据依据面板 | 无三栏布局；相关信息散落在多个卡片 | **缺** |
| 用户反馈 | 有反馈条 + 原因分类 + 补充说明 + 提交审核 | 有 |
| 复制 / 导出 | 复制 SQL、导出 CSV、导出 Excel、收藏 | 有 |
| 状态链 / 查询理解 / 五维校验报告 / 信任条 / 需求澄清 / 增量修改 | **全部真实存在**，且绑定后端业务字段 | 必须保留 |

**诊断**：信息量很大但**没有主次**——十几张卡片平铺，普通员工一进入就要面对「查询理解」「SQL 逻辑自审」「五维校验报告」等技术概念。这正是「看起来像取数管理后台」的根源。优化方向不是删功能，而是**分层收纳**：默认只呈现「问题 → 执行进度 → 结果 → 依据入口」，技术细节收进可展开区与右侧面板。

### 4.2 视觉与设计系统现状

- `:root` 已有 ~59 个 token（`app.css:6-55`），但 **`var(--` 仅 24 次、硬编码 `#` 色值 437 次**，`experience.css` 完全未用 token。
- 两套状态标签并存：`.status-tag`（新）、`.badge-*` / `.rv-chip` / `.trust-chip` / `.tag`（旧，`ask.js` / `history.js` / `admin.js` / `kb.js` 仍在用）。
- `docs/frontend/implementation-report.md` 已把「状态标签统一迁移」「experience.css 合入」「各 tab 页头统一 PageHeader」「响应式与键盘交互」列为**未完成**。
- 现有色板是 Arco `#165dff`；本次方案给定 `#3478F6`。**本次只改设计稿，不动 `frontend/` 代码**；若要前端落地，是一次色板迁移，需单独排期。

### 6.1 关键页面交互说明（交付项）

1. **取数主流程**：进入 → 欢迎语 + 示例问题卡（新增设计）→ 自然语言输入 → 执行时间线 → 结果表格 → 数据依据 → 结果反馈。复制 / 导出 / 收藏 / 提交审核 / 生成自然语言回答为常驻次级操作。
2. **执行时间线**：只展示系统可确认的 8 步（理解业务问题 → 识别指标·时间·维度 → 检索业务知识 → 匹配表与字段 → 生成 SQL → SQL 校验 → 执行查询 → 返回分析结果），四态：等待中 / 执行中 / 成功 / 失败；失败附原因与下一步建议；**不展示模型思维链**。原型为便于评审状态设计默认全展开，真实落地建议**默认收起为一行摘要**（「8 步已全部完成 · 展开查看」），点击展开，让结果表格更靠首屏。
3. **SQL 与执行详情**：SQL 默认折叠，「查看 SQL」展开深色代码区 + 复制按钮；校验报告、查询理解、信任条同属可展开技术区，避免普通员工首屏面对代码。
4. **右侧数据依据面板**：320px 可折叠；展示本次指标 / 相关业务定义 / 使用的数据表 / 关键字段 / 关联知识 / 数据来源；与中央结果区不重复同一信息。
5. **技术信息分层**：状态链四徽章、查询理解、五维校验报告、信任条、需求澄清、增量修改均保留为可展开卡片，不删除任何现有能力。
6. **结果反馈**：反馈条常驻（「这个结果对吗？」/ 结果不对 / 有疑问 / 提交审核），沿用现有 `/api/feedback` 与审核流程。
7. **角色视图**：管理员见全部；普通员工仅见取数相关项。切换只影响导航显隐，**不改变后端权限逻辑**（`_required_role()` 默认 admin）。
8. **规划中能力**：灰显 + 「规划中」标签 + 点击弹出「该能力尚未实现，仅为架构预留」；数据分析工作台四区块全为空状态，无假图表假数字。
9. **抽屉 / 弹窗**：知识详情与审核详情用右侧抽屉；删除与关键配置用居中确认弹窗；ESC / 遮罩关闭。
10. **空 / 加载 / 错误 / Toast**：统一 DS 组件；错误说明原因 + 下一步建议，不暴露技术异常码；评测类页面无真实统计时一律显示「—」并注明需接入真实口径。
