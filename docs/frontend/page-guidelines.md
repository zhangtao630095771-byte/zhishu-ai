# 知数AI 页面布局规范（Page Guidelines）

> 版本：V1.0 ｜ 适用范围：知数AI 全站管理页

所有管理页面遵循统一结构，优先复用公共组件与页面模板。

---

## 1. 页面整体结构

```
页面
├── 页面头部（PageHeader）
│   ├── 页面标题
│   ├── 页面说明
│   └── 页面操作按钮（主按钮 ≤ 1 个，其余次级/下拉）
│
├── 数据统计区域（可选 · StatCard）
│   └── 统计卡片
│
├── 查询筛选区域（可选 · FilterPanel）
│   ├── 搜索框（左侧，明确范围）
│   ├── 筛选条件
│   └── 重置 / 清空
│
├── 主内容区域
│   ├── 列表 / 卡片 / 树形（DataTable）
│   └── 分页
│
└── 辅助区域（Drawer / Dialog）
    ├── 详情抽屉
    ├── 编辑弹窗
    └── 操作确认弹窗
```

并非每页都必须有统计卡片，但**页面标题、主内容区、主要操作区应保持一致**。

---

## 2. 页面头部规范

- 左：页面标题（20px）；下方简短说明（12px 灰）。
- 右：主要操作按钮（主按钮 ≤ 1），其余次级按钮或下拉。

示例：

```
标准问题库                          [+ 新增标准问题] [批量导入]
沉淀标准业务问题与正确取数案例，支持知识复用与 AI 评测
```

---

## 3. 内容容器

- 页面背景统一用 `--color-bg-page`。
- 内容区用白色卡片 `--color-bg-card`，卡片间距统一（16px）。
- 避免多层卡片嵌套、避免无意义大面积留白、主内容区优先利用可用宽度。

---

## 4. 搜索与筛选（统一）

1. 搜索框置于筛选区左侧，明确搜索范围。
2. 筛选器统一高度；支持清空、组合筛选。
3. 筛选变化后重置到第一页；搜索支持回车触发。
4. 条件较多时允许展开/收起。
5. 已选筛选条件应有清晰反馈。
6. 禁止各页采用不同搜索栏排列方式。

---

## 5. 表单规范

- 字段名 + 输入控件 + 辅助说明/校验提示。
- 必填字段明确标识；输入框高度统一；长文本用多行；SQL 用代码区；复杂配置用分组。
- 校验：必填 / 类型 / 长度 / 格式 / 重复 / 提交失败 / 保存成功，不能只靠后端报错。
- 保存为主操作、取消为次操作；提交中禁止重复点击；关闭有未保存内容时提醒；编辑不清空原内容。

---

## 6. 详情 / 弹窗

- 复杂对象用详情抽屉或独立详情页，分区结构：基本信息 / 业务定义 / 关联指标 / 关联数据表 / 标准 SQL / 验证记录 / 审核记录 / 版本信息。
- 简单确认小弹窗、普通编辑标准弹窗、复杂知识大弹窗或独立页。
- 弹窗内容过长时内部滚动，操作区保持可见。

---

## 7. 知数AI 专属展示

- **SQL**：等宽、高亮、复制、折叠；SQL 与执行结果分区；错误清晰标识。
- **表结构**：表名/字段名区分、字段类型单独展示、注释换行、主外键索引统一标识、关联关系统一组件。
- **知识内容**（标准问题/指标定义/业务规则/术语/Golden SQL/Golden Dataset/表知识/实体知识）：统一支持完整内容、关联知识、来源、审核态、验证态、版本、修改历史、引用关系；**核心知识不得单行省略**。
- **AI 评测结果**：区分测试输入 / AI 生成 / 标准答案 / 执行结果 / 结果对比 / 评测结论 / 失败原因；成功/失败/无法判断明确区分。

---

## 8. 响应式（优先桌面）

| 宽度 | 处理 |
|---|---|
| ≥1440px | 完整桌面布局 |
| 1200–1439px | 压缩间距 |
| 992–1199px | 优化列宽，必要时横向滚动 |
| 768–991px | 筛选换行，表格横向滚动 |
| <768px | 基础移动端，复杂表格用卡片或横滚 |

禁止小屏直接压缩所有字段导致不可读。

---

## 9. 页面质量红线（§12）

按钮有反馈、无死按钮、加载/空/错误态明确、操作成功提示、危险操作确认、输入有含义、无重叠溢出、无无意义横向滚动、不改破坏业务功能、重要内容可复制、颜色不作唯一状态识别、控件具备键盘与焦点反馈。
